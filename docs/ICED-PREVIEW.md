# Hunty / iced — экспериментальный клиент

Это начало переноса, а не замена Hunty 0.7.0. Рядом остаётся прежний клиент на Tauri/в браузере. Прототип использует то же P2P-ядро и протокол, но интерфейс и медиастек ещё не перенесены целиком.

Компоновка прототипа ориентирована на 0.7.0: вкладки сверху, чат слева и список чатов и друзей справа. Встроенные аватары мобов взяты из ресурсов 0.7.0; остальные типы аватаров пока заменяются инициалами. Визуальное и функциональное соответствие старому интерфейсу ещё неполное.

В прототипе: регистрация тестового профиля, редактирование ника, статуса, информации о себе и игры, список комнат, добавление друзей по коду и приём заявок, создание групп, вход по коду, копирование приглашения и добавление друзей в них, «Избранное», чтение и отправка текста, ответы, реакции, правки и удаление сообщений. Чаты обновляются по событиям ядра с резервным опросом раз в 15 секунд. Файлы до 6 МБ можно отправить через системный диалог; полученные файлы и изображения можно сохранить. На Linux для диалогов нужен работающий xdg-desktop-portal. Просмотр изображений внутри чата, звонки, видеосвязь, демонстрация экрана, запись клипов, настройки и многие остальные функции старого клиента в iced **ещё не реализованы**. Экспериментальный плеер с перемоткой доступен только в сборке с опцией `native-video`, описанной ниже. Для общения можно добавить друга по коду или создать группу.

```sh
cargo run -p hunty-iced
```

## Экспериментальный плеер клипов

В сборке с `native-video` кнопка «Смотреть» у видеовложения открывает плеер в чате с паузой и перемоткой. Одновременно воспроизводится один клип. Декодирование работает в отдельном потоке, а старые кадры заменяются последним кадром, не накапливаясь в очереди. Временный файл автоматически удаляется при штатном закрытии плеера; после аварийного завершения он может остаться в системной временной папке.

Нужны GStreamer 1.0, его development-файлы и плагины для форматов клипов (для WebM — Matroska, VP8/VP9 и Opus). Плагины аудиовывода нужны для звука. На Linux нужны пакеты gstreamer и plugins-base/good с development-файлами; на Windows и macOS — установленный GStreamer SDK и runtime с плагинами. Плеер проверен на Linux на тестовом WebM; Windows, macOS и разные устройства аудио пока не проверены. Стандартная сборка без этих библиотек продолжает работать без видеоплеера.

```sh
cargo run -p hunty-iced --features native-video
cargo test -p hunty-iced --features native-video
```

Для безопасности прототип по умолчанию хранит отдельный профиль в системном каталоге данных `hunty-iced-preview`. Чтобы проверить копию существующего профиля, скопируй данные в отдельную папку и передай её через `HUNTY_ICED_DATA`. Не запускай два клиента с одной папкой данных; старый Tauri не обязан соблюдать блокировку прототипа. Прежде чем экспериментировать с данными, сделай резервную копию. Windows и macOS пока не проверены.

## Что изменилось в прежнем клиенте

- Локальные HTTP и Tauri-медиаобработчики поддерживают одиночные byte-range-запросы, необходимые для перемотки ранее сохранённых вложений и новых клипов. Клип должен иметь корректный индекс и длительность; неполный или повреждённый файл это не исправит.
- Для демонстрации экрана разрешена адаптация разрешения и fps при перегрузке, а операции над одним WebRTC sender сериализованы. Получение информации о кодеке больше не должно бесконечно задерживать запуск. Это снижает риск зависаний, но само по себе не гарантирует хорошую скорость на любой сети или устройстве.
- Проверки: `node tests/share-sender.mjs`, `node tests/webm-seek.mjs`, `node tests/media-range.mjs` (для обоих нужны ffmpeg и Chromium; последнему также нужен `cargo build -p hunty-node`), `cargo test -p hunty-core media_range`. Для пути к браузеру можно задать `CHROMIUM`.

## Оставшаяся работа

Перенести все окна и действия, сохранить совместимость протокола, добавить нативный захват экрана, устройства аудио/видео, WebRTC, запись/декодирование и перемотку медиа. Для каждой платформы отдельно проверить разрешения, системный выбор экрана, стабильность и производительность с реальными собеседниками. До этого релизы не переключаются на iced.
