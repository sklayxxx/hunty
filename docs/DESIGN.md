# Hunty — дизайн-скилл (правила, по которым делается интерфейс)

Цель: ощущение дорогого приложения (Telegram / Discord / iOS), а не сайта. Всё живое, но лёгкое.

## Движение
- Анимируем только `transform`, `opacity`, `filter` (немного) — никаких width/height/top/left в анимациях.
- Пружины через CSS `linear()` (Chromium 113+): `--spring` (появление), `--spring-soft` (крупные окна), `--ease-out` (уход).
  Длительности: микро 120–160 мс, элементы 220–320 мс, окна 320–420 мс. Уход быстрее появления (×0.7).
- Появление: из точки, откуда пришло (меню — из курсора, окно — из кнопки, сообщение — из поля ввода).
- Списки переставляются через FLIP (запомнили rect → изменили DOM → проиграли разницу), без прыжков.
- `prefers-reduced-motion` и «Лёгкий режим» → анимации мгновенные, стекло без размытия.
- Ничего не крутится бесконечно, кроме того, что сообщает о живом процессе (говорит, грузится, звонит).

## Стекло
- Слои: умеренное размытие фона (blur 16px + saturate 1.35–1.5) → тонировка → верхний блик (inset 0 1px) → градиентная кромка (mask). Матовый режим — blur 8px; без поддержки фильтров — плотная тонировка.
- Не используем SVG-карты преломления, расчёты линз на canvas и пересчёт стекла при ресайзе. Блики и глубина создаются статичными градиентами.
- Блики и кромка — статичные, не анимируются. Обои под стеклом — отдельный слой, размытие обоев задаётся в настройках.
- На одном экране не больше 3–4 крупных стеклянных панелей; мелкие элементы (чипы, кнопки) — без backdrop-filter.

## Текст и цвет
- Минимум 13px для вторичного, 14.5–15px для основного; вторичный цвет не бледнее `--dim` (контраст ≥ 4.5:1).
- Никакого жаргона в интерфейсе: «в сети», «рядом», «через друга», а не «p2p / DHT / relay / ICE». Жаргон — только в «Сеть → Подробнее».
- Цвет ника — личный акцент человека: баннер профиля, кольцо аватарки, упоминание. Белый ник → акцент приложения.
- Упоминание всегда на подложке (`--acc-soft` + кромка), чтобы не сливаться ни с каким ником.

## Контролы
- Ползунок: заполненная часть, ручка с тенью, значение в пузырьке при перетаскивании, двойной клик — по умолчанию.
- Переключатель: ручка едет пружиной, трек меняет цвет; вся строка кликабельна.
- Сегменты: подложка-«капля» переезжает к выбранному.
- Любое действие даёт отклик < 100 мс (нажатие, ripple, смена состояния). Пустые поля/значения не показываем вовсе.

## Проверка перед сдачей (каждый экран)
1. Скриншот 1440×900 и 1100×700, тёмные/светлые обои. 2. Нет обрезанного текста и «дыр» в раскладке.
3. Ховер/фокус/нажатие видны. 4. Esc закрывает, Tab ходит по порядку. 5. Лёгкий режим не ломает вид.
