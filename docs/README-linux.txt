Hunty для Linux — режим «в браузере»
====================================

Это один файл: P2P-ядро + интерфейс внутри. Запускаешь — открывается
http://127.0.0.1:7457 (в Chrome/Chromium/Brave/Edge/Vivaldi — отдельным окном,
если их нет — в браузере по умолчанию, Firefox тоже ок).

Сеть та же, что у Windows-версии: друзья на Windows и на Linux видят друг друга,
коды hunty://add/…, ники, группы, голос, вебки и демки — общие.

Запуск
  ./hunty                         запустить и открыть в браузере
  ./hunty --install               поставить: ~/.local/bin/hunty + «Hunty» в меню приложений
  ./hunty --install --autostart   ...и запускать в фоне при входе в систему
  hunty --uninstall               убрать ярлык, автозапуск и бинарник (данные остаются)
  hunty --help                    все флаги

Как это работает
  - Ядро работает, пока Hunty открыт в браузере, и выключается через минуту
    после закрытия вкладки. С автозапуском (--background) работает всегда:
    тебя видно в сети, история докачивается. Открыть окно — снова «hunty»
    или ярлык в меню (второй копии не будет, откроется уже запущенная).
  - Выключить: Настройки → О Hunty → «Выключить Hunty», или Ctrl+C в терминале.
  - Интерфейс слушает только 127.0.0.1: с других устройств и с чужих сайтов
    к ядру не подключиться.
  - Микрофон, камера и показ экрана: браузер спросит разрешение — разреши.
    Уведомления о сообщениях — тоже через браузер (спросит один раз).

Обновление
  Настройки → О Hunty → «Проверить обновления» скажет, если вышла новая версия.
  Скачай новый архив и снова сделай  ./hunty/hunty --install  (данные останутся),
  потом «Выключить Hunty» и открой заново.

Браузер
  HUNTY_BROWSER=firefox hunty     открыть в конкретном браузере
  hunty --tab                     обычной вкладкой, а не отдельным окном
  hunty --no-open                 ничего не открывать (адрес будет в терминале)

Данные
  ~/.local/share/hunty — ключ (это и есть акк), друзья, группы, история, hunty.log.
  Бэкап: Настройки → Акк → Сохранить ключ. Храни файл как пароль.
  Второй акк на том же компе: hunty --data ~/hunty2  (или HUNTY_DATA=~/hunty2 hunty)

Если друзья не находятся
  - Подожди минуту после запуска: поиск по нику идёт через публичный DHT.
  - Включён firewall (ufw/firewalld)? Задай постоянный порт в Настройки → Сеть
    и открой его (tcp и udp), например:  sudo ufw allow 4777
  - Друзья в одной локалке находят друг друга через mDNS (udp 5353).
