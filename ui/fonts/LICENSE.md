# Шрифты интерфейса Hunty

Все шрифты свободные. Подмножества латиница + кириллица в woff2 собирает `ui/tools/fonts.py`
(исходники — github.com/google/fonts). Файлы `onest-*`, `jbmono-*`, `pix-*`, `nunito`, `comfortaa` —
подмножества из Google Fonts, без изменений.
